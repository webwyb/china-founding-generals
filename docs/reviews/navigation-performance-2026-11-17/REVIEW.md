# 快速返回、阅读状态与打开性能验收

日期：2026-11-17。范围：本地生产 H5。代码、截图和记录尚未提交或部署；工作区原有备案／反馈／AI标识改动保留，本次完整检查包含这些已有改动。人物事实、待核实状态和肖像原件未修改。

## 实现

- 共用导航按顺序提交路由，等待目标页实际挂载；准备阶段可以取消，连续操作只执行最后一个尚未提交的意图，重复点击合并。关闭 H5 路由滑动转场，避免旧页面加载与下一次返回交错。
- 人物页先并行准备页面代码和对应资料再切换；返回名录使用确定的路由，并恢复本次浏览的筛选、搜索、铭记范围、加载批次、实际 Taro 滚动位置与人物链接焦点。刷新重新创建内存状态，仍恢复全部。
- 浏览器发布包只携带轻量名录。完整人物资料按版本路径分别输出，页面直达时通过 HTML 内联当前人物完整资料；全文搜索索引在首次搜索聚焦／输入后读取，保留原有生平检索范围，含加载、失败与重试状态。
- 首页地区统计和群像移到模块级预计算；相关人物使用缓存计算。构建继续生成1614份完整人物静态正文及1618条站点地图地址。
- `dev:h5` 不执行静态生成，因此开发模式继续使用完整资料；生产 H5 才启用拆分。实际配置在 development/h5、production/h5、production/weapp 三组环境分别断言为 false、true、false。

基线是上轮发布 `4186f87` 的隔离构建，其55份 src/config/package文件与该提交逐字节匹配。本轮结果来自当前工作区，包含另一轮原有合规改动。下表为文件字节和 Node 默认 gzip 估算，不是网络耗时或首屏性能评分。

| 项目 | 上轮 | 本轮 | 减少 |
| --- | ---: | ---: | ---: |
| 公共 JS 原文 | 7,855,798 B | 754,384 B | 90.4% |
| 公共 JS gzip | 668,429 B | 100,659 B | 84.9% |
| 所有应用 JS 原文，含后续页面分包 | 8,247,956 B | 1,152,801 B | 86.0% |

## 真实浏览器操作

使用内置浏览器访问 `http://127.0.0.1:5173` 的生产构建，实际 CSS 视口1280×720、390×844、320×812。连续进入和返回之间未插入人为等待，均通过页面控件操作。没有执行浏览器注入式导航。

- 最终生产分包：桌面20轮、390px手机10轮、320px窄屏5轮，进入人物后立即点返回，35轮全部回到名录。另测浏览器原生返回5轮，搜索、31人结果和位置保留。
- 组合为“少将／湖南／红军”，自动追加到31人后往返，军衔、家乡、搜索、批次保留；首次 Enter 聚焦人物时浏览器会先滚动链接，之后9轮返回均为4659.5 CSS px，并恢复该人物链接焦点。没有把聚焦导致的导航前滚动写成恢复误差。
- 纪念卡→人物连续3轮确认可见页标题为“黄忠诚”，再返回名录保持上述组合。生成异步任务未导致跳回旧页。
- “我的铭记”范围往返仍为1人；人物页移除铭记后返回立即更新为0人及空态。临时添加的铭记已移除。
- 刷新恢复空搜索、全部军衔／家乡和初始24人；铭记数据独立保存。390px、320px和桌面所测页面未见横向溢出。
- 直接打开人物页保留完整7段生平与11条足迹，内联资料存在，交互应用替换静态正文后内容完整；首页入口正常。测试页捕获的错误／警告日志为空。

浏览器只读环境未提供 Performance API，因此没有给出 LCP、冷启动秒数、慢网或 CPU 基准，也未进行物理手机、微信、读屏、其他浏览器引擎或线上验收。
