# 筛选联动与人物详情页验收

日期：2026-11-17。本地生产预览：`http://127.0.0.1:5173`。本文件保留本地验收阶段记录；提交和上线结果见 [正式发布验收](../filters-profile-deployment-2026-11-17/REVIEW.md)。

## 筛选行为

- 家乡选项和人数随军衔、搜索、“我的铭记”范围联动；计算家乡分布时忽略家乡自身条件，选择家乡后结果总数使用完整条件。
- 元帅显示四川4、湖南3、湖北1、山西1、广东1，共10位。湖南筛选显示3位；山西切换到大将时自动恢复全部家乡，共10位。仍有效的家乡保留选择。
- 搜索李贞时仅显示湖南1位；没有结果时不再显示误导性的全库地区人数。展开按钮只在确有隐藏地区时出现。
- 标签、搜索、筛选、已加载批次及滚动位置只保留在本次页面生命周期内存；刷新恢复全部1614位，旧持久化筛选不再读取。人物收藏仍由独立服务持久保存。
- 地区入口先应用地区，再移除入口参数；山东入口实际显示88人，刷新同一网址后恢复全部。详情返回保留当前浏览：少将48人批次和非零阅读位置均已观察。

## 详情设计与两轮自审

沿用瓷白`#f4f7f3`、黛墨`#203d43`、松青灰`#60736c`、朱砂`#a23f32`、浅青线`#d5dfd7`；宋体承担姓名与故事，系统无衬线承担控件与辅助说明。复用Shell、Button、Portrait、Dialog、Landscape和既有出处、时间轴，不新增组件体系或装饰编号。

第一轮缩短山河封面（桌面250px、手机156px），把姓名、军衔、生卒整合为身份信息块，改正手机长姓名依赖固定上边距的对齐；调整简介、正文、段落和背景说明层级。历史肖像继续完整等比显示，原件及人物事实未改。制作纪念卡的文字及箭头在桌面和手机保持一致。

第二轮针对实际滚动调整：导航吸顶并标记当前章节，跳转后留出导航高度、焦点移到标题，资料入口会展开出处。初版时间轴定位76px而判断阈值偏小，已修正并复测高亮与焦点。900px以内采用单列阅读，768px实测正文654px，避免时间轴挤窄正文。320px长姓名、待核实地域及缺图占位均已复核。

## 实际验证

最终完整 `npm run check` 退出码0：类型、186种组合筛选、动态地区统计、无效地区清理、新生命周期忽略旧筛选、资料离线复现、1614人、1609张肖像、全部卡片构图／二维码、H5构建及1614份完整人物HTML和1618条站点地图均通过。仅移除了设计检查中重复且已过时的持久化状态断言，新的状态与联动检查统一放在功能校验中。

浏览器为桌面Chrome，实际CSS视口2133×1064（截图2132×1064）；Codex内置浏览器实际320×812、390×844、768×900。检查筛选联动、刷新重置、48人返回、搜索空态／清空焦点、详情长文、时间轴、资料展开、原图弹层及Esc后焦点恢复。键盘Enter在应用加载完成后定位时间轴，焦点在目标标题、导航在顶部、标题在约76px。测量页面转场结束后无横向溢出，临时视口已恢复。

一次测试发生在本地构建替换分包期间，旧页面动态模块加载失败；最终构建完成后刷新并重新走完名录→人物→返回，48人状态保留。初始静态壳加载期间的一次键盘按键没有计入成功验收，已等待交互应用接管后复测通过。没有把自动适配器测试写成浏览器操作。
