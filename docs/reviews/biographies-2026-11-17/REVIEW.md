## 自审修正

排除前句年份泄漏、给一串历任岗位定同一年、阶段标题未重置、断裂单位编号、亲属或其他指挥员误归本人、把纪念文集算作本人著述等问题。早期非红军岗位使用中性阶段标题；旧单条履历不再直接生成时间轴。南方游击战争人物不因文中提到中央红军长征而自动关联为本人参加长征。

真实操作还发现Taro在复用已有页面时可能保留旧人物参数；已在人物和卡片页同步H5地址ID，并复现原操作验证修正。最后的完整 `npm run check` 通过：类型、10项离线生成复现、目录与段落来源、186种组合筛选、1614人遍历、12项既有回归、15项生平回归、1609张肖像两种构图和3228个卡片文字布局，以及H5构建。
