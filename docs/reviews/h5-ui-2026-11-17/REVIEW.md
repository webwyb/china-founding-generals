# H5 UI与交互复核 · 2026-11-17

本轮使用仓库中的 `docs/skills/frontend-design/SKILL.md`，沿用瓷白、松青、黛墨、朱砂和中文宋体。范围为首页、名录、人物档案、纪念卡及其弹层，不改人物事实、史料差异状态或肖像原稿。

## 设计与迭代

色彩继续使用瓷白 `#f4f7f3`、黛墨 `#203d43`、松青灰 `#60736c`、朱砂 `#a23f32`、浅青线 `#d5dfd7`。标题与人物阅读使用 Shanhe Serif；操作与说明使用系统字体。保留真实群像与家乡景观作为识别重点，正文左对齐，操作顺着阅读方向排列。

```text
手机名录                   手机纪念卡
标题 / 名录与铭记           返回人物
搜索                       标题 / 样式选择
军衔 / 常见家乡 / 展开      最终PNG预览
结果数量                   保存说明
人物 人物                  固定：复制链接 / 保存
接近底部追加24人
手动加载 / 返回筛选
```

沿用现有组件和素材，经过基础控件、真实流程、极端内容、首屏阅读四轮检查：

- **控件实际生效。** Chrome实测发现Taro会将CSS里的 `button` 标签选择器改写成 `taro-button-core`，导致H5原生按钮丢失局部布局和焦点样式。共用Button新增 `.ui-button`，基础、标签与样式选项统一用类名绑定。
- **图标与对齐。** SVG仍用24×24坐标，`--icon-size`同时控制宽高，图标不获取焦点；触控筛选、清空、关闭等区域保留44px。人物按钮显式顶部排列，修正不同文案长度导致的肖像行垂直偏移。悬停仅对可悬停指针生效。
- **连续浏览。** IntersectionObserver在底部前480px追加24人，保留手动按钮。键盘手动追加时聚焦新增首项，自动追加不抢焦点。合并本地存储写入，记录实际Taro页滚动；返回、刷新继续保留已加载人数和位置。
- **手机阅读。** 搜索框16px，支持组合输入与清空后的焦点保留。默认六个常见家乡与首页一致，选中的其他地区继续显示。手机故事列表改为横向图文，标题按短语换行；长姓名按姓名片段排版，避免中点或末字孤行。
- **卡片与弹层。** 手机上先选样式，再看最终PNG；桌面保留左图右操作。保存／原图弹层标题和关闭入口在内部滚动时保持可见。背景控件inert、页面滚动锁定，关闭后恢复焦点。预览与保存继续使用同一成图。
