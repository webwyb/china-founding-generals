# 部署流程拆分验收

日期：2026-11-17。范围为 GitHub Actions、制品和发布脚本；没有修改人物事实、网页交互、云权限、服务器接收器或 HTTPS 配置。

## 改动

- `assets.yml` 独立增量同步 COS；`ci.yml` 三系统检查后只发布网页。
- Ubuntu 打包时移除静态素材正文；deploy 不再检出仓库、下载大素材制品或安装 COS SDK。
- 网页发布用公开 HEAD 确认素材存在及长度，失败在 SSH 之前停止，旧站点继续服务。素材缺失只等待180秒；已就绪对象不重复检查。
- 纯 Markdown、`docs/**` 与 `data/testing/**` 跳过构建部署。构建期间仅有文档追加时允许原应用提交发布；新的应用变更仍阻止旧版发布。
- 代码及素材清单摘要在部署时核对，`version.json` 按本次部署 attempt 生成，支持单独重跑 deploy。
