# 视觉与交互约定

作品定位是公众可分享的数字纪念馆。用真实人物、家乡与具体经历建立阅读入口，避免把人名变成无差别统计数字。

| 色彩 | 当前值 | 用途 |
| --- | --- | --- |
| 瓷白 | `#f4f7f3` | 页面与纸笺底色 |
| 黛墨 | `#203d43` | 正文与主要标题 |
| 松青灰 | `#60736c` | 辅助说明 |
| 朱砂 | `#a23f32` | 行动、印章、重点 |
| 浅青线 | `#d5dfd7` | 分隔与边框 |

标题和故事使用本地Noto Serif SC子集，内部字体名 `Shanhe Serif`，保留400—600字重；控件使用系统中文无衬线，日期使用等宽数字特性。手机输入字号至少16px，长姓名可换行，保持键盘可见焦点。

首页用肖像群像，详情用山河封面与独立肖像。地区景观对应关系统一在 `src/data/landscapes.ts`，不得在不同页面各写一套映射。地域待核实时不推测景观。

历史照片完整等比展示，允许画框留白。保留帽子、面部、肩章和原图所含勋章；不使用铺满裁切、人像灰度滤镜、悬停放大或覆盖主体的导航装饰。原图本身分辨率不足或已裁切时，不能假称已恢复高清和完整内容。

H5纪念卡由 `cardRenderer.ts` 统一绘制，预览与下载直接共用1200×1800 PNG。两种样式也必须统一处理待核实资料。人物图片与景观分别呈现，不用AI修改人物身份。

底部操作栏考虑安全区与页脚阅读空间；弹窗支持Esc、焦点约束、恢复触发控件和实际Taro页滚动锁定。响应式断点主要为1100、760和374px。减少动态效果的系统偏好得到尊重。代码适配完成不等于已经通过浏览器与真机验收，状态见 `QA.md`。

本次使用的 `frontend-design` 技能副本与原始许可在 `docs/skills/frontend-design/`。该副本来自本次开发环境已安装的技能目录；环境未提供可核实的原始仓库元数据，不虚构安装来源。换机后可直接阅读该副本，也可按目标工具的技能安装机制安装。
