# 视觉与交互约定

作品定位是公众可分享的数字纪念馆。用真实人物、家乡与具体经历建立阅读入口，避免把人名变成无差别统计数字。

| 色彩 | 当前值 | 用途 |
| --- | --- | --- |
| 瓷白 | `#f4f7f3` | 页面与纸笺底色 |
| 黛墨 | `#203d43` | 正文与主要标题 |
| 松青灰 | `#60736c` | 辅助说明 |
| 朱砂 | `#a23f32` | 行动、印章、重点 |
| 浅青线 | `#d5dfd7` | 分隔与边框 |

标题和故事使用本地Noto Serif SC子集，内部字体名 `Shanhe Serif`，保留400—600字重；控件使用系统中文无衬线，日期使用等宽数字特性。手机输入字号至少16px，长姓名可换行，保持键盘可见焦点。

首页用肖像群像，详情用山河封面与独立肖像。地区景观对应关系统一在 `src/data/landscapes.ts`，不得在不同页面各写一套映射。地域待核实时不推测景观。

历史照片完整等比展示，允许画框留白。保留帽子、面部、肩章和原图所含勋章；不使用铺满裁切、人像灰度滤镜、悬停放大或覆盖主体的导航装饰。原图本身分辨率不足或已裁切时，不能假称已恢复高清和完整内容。

H5纪念卡由 `cardRenderer.ts` 统一绘制，预览与下载直接共用1200×1800 PNG。两种样式也必须统一处理待核实资料。人物图片与景观分别呈现，不用AI修改人物身份。

H5两种纪念卡的右下角绘制人物档案二维码，左侧保留纪念句、扫码提示、正式域名及资料说明。正式HTTPS域名统一读取 `config/site.json`，人物地址由 `personLinks.ts` 生成，不把本地预览地址写进图片。二维码采用Q级纠错、整数模块和四模块纯白静区，使用黛墨色，不叠加标志或装饰；每模块4个PNG像素，版本随链接长度选择。二维码属于同一Canvas成图，不能只叠放在页面预览上。独立解码器、缩小压缩成图与真实页面分别验收，不能把软件解码结果写成手机实扫。

SEO预生成复用实际React页面，不制作只给爬虫看的隐藏正文。人物、首页和名录完成挂载后替换同内容的静态首屏；完整档案索引和资料说明保留可独立阅读的静态HTML。跳转使用带真实href的共用Button链接分支，普通点击保留应用导航，修饰键保留浏览器原生行为。档案索引采用现有色彩、宋体与分隔线，按军衔组织姓名、家乡与生卒，不增加另一套卡片组件。

底部操作栏考虑安全区与页脚阅读空间；弹窗支持Esc、焦点约束、恢复触发控件和实际Taro页滚动锁定。响应式断点主要为1100、760和374px。减少动态效果的系统偏好得到尊重。代码适配完成不等于已经通过浏览器与真机验收，状态见 `QA.md`。

本次使用的 `frontend-design` 技能副本与原始许可在 `docs/skills/frontend-design/`。该副本来自本次开发环境已安装的技能目录；环境未提供可核实的原始仓库元数据，不虚构安装来源。换机后可直接阅读该副本，也可按目标工具的技能安装机制安装。

## 2026-11-17控件与浏览细节

- 共用按钮以 `.ui-button` 绑定基础、禁用、焦点与局部样式。Taro的H5样式转换会把 `button` 标签选择器改成 `taro-button-core`，不能依赖它为原生按钮设置样式。
- 图标统一24×24绘制坐标，以 `--icon-size` 同时控制宽高（常用16、17、20px）。图标不接收焦点；独立操作区域至少44px。悬停反馈仅用于可悬停指针，手机使用按压反馈。
- 人物卡片显式顶部排列，人像与标题行对齐；手机故事和相关人物使用横向图文列表，保留完整肖像和完整文案。长姓名按姓名片段换行，手机长姓名的军衔放在姓名下方。
- 名录默认显示与首页一致的六个常见家乡，已选择的其他地区继续可见，其余按需展开。手机压缩非操作留白，保持筛选44px点击高度。接近底部480px时追加24人，手动加载保留，键盘焦点落在新增首项；追加不重排已有项目，不使用人为加载延迟。
- 搜索使用16px原生H5输入控件，组合输入结束后应用检索，清空保留输入焦点。筛选、已加载数量和实际滚动位置仅保留在本次页面生命周期的内存中；从详情返回保留阅读进度，刷新恢复全部，不读取旧持久化筛选。铭记人物仍由独立收藏服务长期保存。
- 手机纪念卡先选样式、后看最终PNG；桌面保持左预览、右操作。保存和原图弹层标题、关闭按钮在弹层滚动时保持可见，背景隔离并锁定页面滚动。真机与跨引擎状态以QA记录为准。


## 筛选联动与详情阅读细调（2026-11-17）

家乡选项与人数由当前军衔、搜索和铭记范围共同计算，计算时忽略家乡自身筛选，便于在不同地区之间继续切换；选择地区后结果总数按完整条件计算。军衔变化时保留仍有效的家乡，无对应人物时恢复“全部”。地区入口参数应用一次后从地址移除，刷新同样回到全部。

人物页保持原色彩和完整肖像，桌面山河封面250px、手机156px。姓名、军衔和生卒组成稳定的身份信息块，不用固定上边距硬推长姓名。生平正文保持宋体，手机17px／2倍行高；宽屏正文与时间轴双栏，900px以内改为单列。阅读导航吸顶、标记当前位置，跳转后正文留出导航高度，并将焦点交给目标标题；资料出处展开时保留真实来源。阶段分隔、背景说明和辅助出处各有清楚层级，不增加装饰编号或新的组件体系。

## 备案与反馈入口（2026-11-17）

页脚沿用现有宋体、细线和松青灰，版权、勘误、AI景观与真实备案链接可换行且保持44px操作高度及可见焦点。说明页复用正文段落与章节样式，不新建表单组件；具体人物通过预填姓名与正式地址的邮件草稿反馈，说明页同时公开邮箱。静态说明页使用真实链接，保留无应用脚本的可用性。

AI景观提示同时出现在首页、人物封面、卡片说明和图片替代文字中。景观纪念卡在共享PNG内部、肖像之外以瓷白底黛墨字标明“背景景观由AI生成”，不遮挡历史人像；素笺或未配置地域的构图不放该标签。原始图片不修改，显式标识的实现范围及进一步核验见 [COMPLIANCE.md](COMPLIANCE.md)。

## 连续导航与加载反馈（2026-11-17）

H5页面切换取消路由滑动动画，快速操作以最后尚未提交的意图为准；资料准备阶段保留当前完整页面，用小型状态提示表示正在打开，不遮挡返回入口。详情返回名录恢复浏览位置并把键盘焦点交回人物链接。全文检索首次加载使用紧凑状态与明确重试入口，等待时不展示错误的匹配人数；资料和搜索的优化不删除正文或扩大用户筛选范围。


## 品牌更新（2026-11-17）

两端统一名称为“名在山河”，品牌短句为“名字留在山河，记忆有其来处。”，集中配置在 `config/brand.json`。沿用瓷白、松青、黛墨、朱砂与宋体，以用户选定的山河书页头像替代页眉文字印章；不改变人物历史肖像。

原稿位于 `design/brand/ming-zai-shan-he/avatar-v1.png`，提示词与简介同目录保留。`public/brand/icon.png`（192px）、`favicon.png`（32px）、`avatar-512.png`（512px）由同一原稿等比缩放，未裁切或重绘；分别用于两端页眉／纪念卡、网页标签图标、微信管理后台头像上传。微信图标随主包本地打包，避免依赖新增远程对象；H5 生产遵循现有素材发布流程。

品牌落款进入共享 Canvas，预览和下载保持同图。网站域名、人物链接、数据ID、本地铭记存储键与内部字体名维持兼容，不因展示名称更新而丢失记录或破坏已有二维码。旧验收文档中的历史名称保留原貌。
