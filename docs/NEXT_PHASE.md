# 名在山河：下一阶段推进

开始日期：2026-11-18。范围：H5／PC；共享页面对微信保持可编译，不把编译当作真机验收。品牌沿用“名在山河”，当前旗舰内容仍是开国将帅。

## 产品假设与交付顺序

1. **十位元帅精品导览**：十位全部收录，逐段出处、关键节点、完整档案入口、可恢复的自报阅读进度；首页和人物页可进入专题。保留林彪后期历史结论和原档案的资料不确定性。完成自动检查及实际H5浏览器验收；移动设备保存／分享需真人真机参与，不能由桌面模拟代替。
2. **上海地方专题试点**：十位人物跨军政、科技、教育、文学、出版与社会事业。按实际关系区分出生、求学、工作、居住和纪念地，逐条保留来源。不增加将帅人数，不给其他领域人物套军衔和将帅纪念卡。没有核验肖像的条目使用姓名排版，不生成或移用人像。
3. **凭证据决定后续方向**：准备读者测试任务、反馈入口、记录模板与决策门槛。现有RUM继续仅提供既有访问统计；不擅自新增外部点击、搜索词或阅读明细上报。先用自愿访谈与访客主动发送的反馈收集证据。没有真实读者数据前不宣布需求验证成功或确定商业方向。

## 本轮设计计划

- 色彩复用瓷白 `#f4f7f3`、黛墨 `#203d43`、松青灰 `#60736c`、朱砂 `#a23f32`、浅青线 `#d5dfd7`。
- 宋体用于专题标题、人物名字及叙述；系统字体用于目录、进度和操作。正文宽度不超过约36个汉字，手机保持可读字号。
- 专题入口是两篇有明确阅读承诺的导览。详情为“题记—人物目录—逐人阅读—延伸专题—反馈”，桌面目录置左，手机目录按需展开。
- 将帅保留完整等比历史肖像；地方专题用人物姓名、领域与真实地点关系建立识别，不引入装饰景观或新图像。
- 自检：不用重复统计数字充当专题主视觉，不把人物段落切成一排同样的卡片；以连续文章和章节目录呈现。编号仅表示真实阅读次序。

## 读者验证与方向判断

邀请须由用户自行进行，或另行明确授权；本轮不向任何人发送消息。建议先做12次自愿测试：一般读者、学生／家长、教育或地方文化工作者各4人。该样本用于发现问题，不作总体市场推断。

每次约15分钟，先不解释功能，完成以下任务：

1. 从首页选择一条专题，阅读一位原本不熟悉的人物，说出一件记住的事。
2. 自行找到该叙述的出处，解释人物与地方的关系；上海条目尤其检查是否被误解为“上海籍”。
3. 自由决定是否继续阅读第二人、打开完整档案或另一专题；记录理由，不用任务强迫产生转化。
4. 询问最想继续阅读的方向、愿意在什么场景再次使用，以及内容／操作上的困惑。分享和保存单独在真实iOS／Android／微信设备验证。

记录：匿名受访编号、读者类型、设备与浏览器、实际操作与口述、是否独立完成、是否主动继续、困惑、内容需求。不要采集姓名、联系方式、学校、搜索词或铭记清单；自愿引用原话前取得许可。测试流量与真实自然访问分开。

方向判断预先约定为探索性门槛：

- 12人中至少9人能独立找到出处并正确解释地点关系；否则先修内容与导览，不扩大收录。
- 至少6人自发读第二位，且能说出内容上的理由；不足时继续修订故事与推荐。
- 某方向至少4人自发提出相近需求，且另有至少2次对应角色访谈确认真实使用场景，才启动下一批内容；允许多方向并列，也允许暂不扩展。
- 教育或机构合作需要进一步验证使用频率、制作／审校成本及真实合作意愿；兴趣表达不等于采购或收入。
